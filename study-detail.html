01. 과정 소개

이 과정은 코드를 많이 외우는 수업보다 하나의 사이트를 끝까지 완성하는 경험에 집중합니다. 무엇을 만들지 정하고, 정보를 구조화하고, 화면을 설계하고, 실제 웹으로 구현합니다.

02. 이런 사람에게 추천합니다

  • 디자인한 화면을 직접 구현하고 싶은 디자이너
  • 브랜드나 서비스 사이트가 필요한 예비 창업자
  • 실제 결과물이 포함된 포트폴리오를 만들고 싶은 사람
  • HTML과 CSS를 프로젝트 중심으로 배우고 싶은 입문자

03. 커리큘럼

01

문제와 목적 정의

웹사이트가 해결할 문제와 목표 사용자를 정리합니다.

02

정보 구조 설계

메뉴와 페이지, 콘텐츠의 우선순위를 구성합니다.

03

피그마 디자인

반응형 화면과 공통 컴포넌트를 제작합니다.

04

HTML과 CSS 구현

디자인을 실제 웹 화면으로 옮깁니다.

05

GitHub 배포

완성된 사이트를 온라인에 공개합니다.

04. 과정이 끝나면 남는 것

배포 가능한 개인 웹사이트, 기획 문서, 피그마 화면, GitHub 저장소와 직접 개선할 수 있는 기본 웹 제작 흐름이 남습니다.

PROJECT BASED

예제를 따라 만드는 데서 끝나지 않고 자신의 주제와 콘텐츠로 결과물을 완성합니다.

05. 신청 안내

모집 일정과 진행 시간, 준비물은 스터디 오픈 전에 공지합니다. 신청이 열리면 로그인 회원에게 먼저 안내할 예정입니다.
